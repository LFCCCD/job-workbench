# 求职工作台 v0.2.1 M2 Beta

Windows x64 M2 Beta 界面设置热修复。

## 变更

- 新增独立“设置”页面
- 齿轮图标固定显示在左侧栏左下角
- 系统通知、Windows 登录自启和自动检查更新移入设置
- 系统页仅保留健康状态、备份、数据路径和脱敏诊断
- 设置入口使用独立齿轮图标和激活状态

## 安装

下载并运行 `Setup.0.2.1-m2.exe`。从 `v0.2.0-m2` 升级不会覆盖本地数据库。

## 已知限制

- 当前安装包未配置代码签名证书，Windows 可能显示 SmartScreen 提示
- 自动更新只检查版本，不静默安装
- 登录自启只支持 Windows 安装版
