# 求职工作台 v1.0.0 正式版

Windows x64 本地求职工作流正式版。

## 核心能力

- 岗位手动新增、编辑、筛选、收藏、状态时间线和回收站
- 专用 Edge 中的 BOSS 低频采集、候选预览和人工确认导入
- BOSS 风格城市目录、关键词气泡、搜索缓存和详情补全任务
- 本地规则预分析，以及 DeepSeek、DashScope、自定义 OpenAI 兼容 Provider
- JD 原句和已核实事实 ID 证据校验
- 简历个人资料、事实库、核实状态、岗位版本和 PDF 导出
- 联系人、跟进待办、面试记录和到期统计
- Windows 托盘、系统通知、登录自启和更新检查
- 系统健康页、14 天日志和脱敏诊断报告
- SQLite 迁移、一致性备份、恢复和旧版数据兼容
- 应用内 BOSS 链接统一使用专用 Edge，复用登录状态

## 安全与数据

- 不自动投递、不自动发送招聘消息
- 不绕过验证码、登录风控或访问频率限制
- AI API Key 使用 Electron `safeStorage` 加密
- 联系人、简历正文、Cookie 和 API Key 不进入诊断报告
- 更新检查不静默下载或执行安装包

## 安装

下载并运行 `Setup.1.0.0.exe`。默认数据目录：

`%LOCALAPPDATA%\JobHunter`

升级不会覆盖数据库。建议在重大操作前创建备份。

## 已知限制

- 当前安装包未配置代码签名证书，Windows 可能显示 SmartScreen 提示
- BOSS 页面或接口改版时，采集适配器可能需要维护
- AI 本地预分析是关键词与证据规则，不是语义大模型
- 多岗位 AI 横向比较、云同步和移动端尚未包含
